\begin{macro}{\toup}
  Math spacing in subscript of limits is kinda odd. So typesetting 
  \begin{gather}
    \lim_{R\mathrel{\uparrow} 1}\\  
    \lim_{R\mathrel{\to} 1}\\       
    R\mathrel{\uparrow} 1\\
    R\mathrel{\to} 1
\end{gather}
leads to odd spacing. Create custom command \verb|\toup| to fix this. Here is a nice analysis on the geometry of those kerning: \clink{https://tex.stackexchange.com/questions/327486/typesetting-a-limit-from-below-correctly}
\end{macro}
